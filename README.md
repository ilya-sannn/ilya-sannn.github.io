Эталонные форматы ценников ритейла (Нажмите для проверки)
1. QR-ценник со ссылкой и ценой (Магнит / X5 стиль)
...price?store=104&ean=4607065000129&price=149.99
EAN + Цена
2. JSON QR-код с ценника (DNS / Складской ценник)
{"sku":"90124","barcode":"4601234567893","name":"Молоко...","price":89.50}
JSON → EAN
3. GS1 / Честный Знак (GTIN-14 → EAN-13)
0104607025392400215abc93dGVzdA==
GTIN → EAN
4. Весовой штрихкод из QR ценника (Префикс 21: PLU + Вес)
QR_TAG:2104512008459;PRICE=340.00 (PLU 04512, Вес 0.845 кг)
